# أيهم 🌙 — لعبة رعب عراقية لـ Android TV

رعب وبقاء في صحراء الأنبار: قرية طينية مهجورة، نخيل، آبار، عاصفة ترابية، و«السعلوة» تتجول في الظلام.

## الهدف
اعثر على **مفتاح السيارة + جالون الوقود + بطارية السيارة** ثم اذهب إلى السيارة القديمة
في الزاوية الجنوبية الشرقية. السعلوة تكره الضوء: وجّه المصباح نحوها بثبات لتهرب.
لا تركض كثيراً — الصوت يجذبها.

## التحكم (يد بلوتوث فقط)
| الزر | الوظيفة |
|---|---|
| العصا اليسرى | حركة |
| العصا اليمنى / D-Pad يمين ويسار | دوران |
| RT / LT / RB / LB / L3 | ركض |
| X أو Y | مصباح |
| A / B | تأكيد / رجوع (وإغلاق الورقة) |
| Start | إيقاف مؤقت |

القائمة الرئيسية والإعدادات (الصوت، الجرافيكس 4 مستويات، الحساسية، المنطقة الميتة، الاهتزاز) كلها تُدار باليد.
ريموت التلفاز (الأسهم + OK) يعمل في القوائم أيضاً.

## الحصول على APK بدون كمبيوتر (من الآيفون)
1. افتح github.com من Safari وسجّل الدخول، ثم **New repository** باسم `layalina` (Public).
2. **uploading an existing file** ← ارفع كل محتويات هذا المجلد **مع الحفاظ على المسارات**
   (خصوصاً `.github/workflows/build-apk.yml` و `www/` و `scripts/`).
   إن صعب رفع مجلد مخفي من الآيفون: أنشئ الملف يدوياً من **Add file → Create new file**
   واكتب المسار `.github/workflows/build-apk.yml` ثم الصق محتواه.
3. من **Settings → Actions → General → Workflow permissions** اختر **Read and write permissions**.
4. من تبويب **Actions** شغّل **Build Layalina APK** (Run workflow) وانتظر ~5–10 دقائق.
5. بعد النجاح يظهر رابط التحميل المباشر في:
   `https://github.com/<اسم-حسابك>/layalina/releases/download/latest/Ayham.apk`

## التثبيت على Android TV
- ثبّت تطبيق **Downloader** على التلفاز، افتحه وأدخل رابط الـAPK أعلاه، ثم ثبّت.
  (فعّل «التثبيت من مصادر غير معروفة» لتطبيق Downloader عند الطلب.)
- ستجد «ليالينا» في قائمة التطبيقات. وصّل يد البلوتوث من إعدادات التلفاز، واضغط أي زر داخل اللعبة.

## ملاحظات
- المحرك: HTML5 Canvas (Raycasting) مغلّف بـ Capacitor، والصوت مولَّد بالكود (لا ملفات صوت خارجية).
- للأجهزة الضعيفة اخفض الجرافيكس إلى «منخفض» أو «متوسط».
- الـAPK موقّع بمفتاح debug وهو مناسب للتثبيت اليدوي، وليس للنشر على Google Play.
